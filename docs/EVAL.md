## Drying score: capture rate and lift

Run 2026-10-17, region `riau`, top 10.0% of cells.

| Year | Weeks | Detection-weeks (n) | In top 10% | Capture rate | Lift |
|---|---|---|---|---|---|
| 2019 | 25 | 3,573 | 959 | 26.8% | 2.68x |
| 2023 | 25 | 3,273 | 772 | 23.6% | 2.36x |
| 2026 | 18 | 362 | 6 | 1.7% | 0.17x |

How it was made. For each ISO week of the year that `bara.cell_weekly_drying` holds (the commands below score weeks 20 to 44 of 2019 and 2023; 2026 holds the live weeks), take the top 10.0% of the region's peat cells by `drying_score`. Count the MODIS FIRMS detections (`bara.firms_detections`, the same detections the re-ignition labels use) that fall inside a peat cell 1 to 4 weeks after the scored week, and the share of them inside the top cells. That share is the capture rate; lift is the capture rate divided by 10.0%, so 1.00x is no better than chance. Counts are pooled over the weeks: a detection is counted once for each scored week whose window holds it (up to 4 times), so the n column counts detection-weeks, not distinct detections. A week counts only when its window ends on or before 2026-10-15: the detection table is rebuilt daily from FIRMS up to the day before the newest image, and this date is its last rebuild minus 2 days, so a window with no detection before it is a real zero, not missing data. The 2019 and 2023 weeks were scored with the same `jobs.drying_score` as the live weeks. Rows: `bara.eval_drying`.

A year with few hotspots inside the peat cells (see the n column) gives a rate that rests on a small count.

```sh
cd services/pipelines
for w in $(seq 20 44); do
  uv run python -m jobs.drying_score --region riau --week 2019-W$w
  uv run python -m jobs.drying_score --region riau --week 2023-W$w
done
uv run python -m jobs.eval_drying --region riau
```

How it was made. `jobs.train_reignition` trains a BigQuery ML logistic regression on the 2015 to 2024 Riau fire events and scores the 2026 test events, which the model never sees. The served model leaves out rain after the quiet date, which is not known on the day.
